## 里程碑插件 v2.5.2：性能 / 内存 / 缺陷（行为不变）
- **农历换算改前缀和**：`lunar.js` 新增 `YEAR_LEN`/`YEAR_OFF` 索引表（模块加载时由 `rawYearDays` 建一次），`solarToLunar` 先按平均年长 354.367 估下标再用前缀和校正，`lunarToSolar` 直接取 `YEAR_OFF[ly]`。原实现每次从 1900 年逐年累加（O(年份数)）→ 实测 solarToLunar 3.5×、lunarToSolar 3.8×、农历 nextOccurrence 3.5×。73,384 天往返校验仍 0 失败
- `event-core`：`YMD_RE`/`HEX_COLOR_RE` 提升为常量、`festivalByKey` 改 `Object.create(null)` 哈希表、`normalize` 里 `parseYMD` 只调一次、新增 `daysFromTs(aTs,b)` 让 nextSolar/nextLunar 循环里不再反复取 a 的日号、`cycleProgress` 支持第三参 today、`uid()` 加序号位（同一毫秒不撞）、`normalize` 去重 id
- `app.js`：`computeRows(today)` 一次性算好 `label`/`name`（原来 itemHtml、renderHero 各自再算 1-2 遍农历）；`renderList`/`renderHero` 用 `listKey`/`heroKey` 字符串比对，内容没变不写 innerHTML（顺带不再重播 `cd-in` 动画）；`hexToRgb` 加 128 条上限缓存
- **主题检测**：`setInterval(detectTheme, 3000)` + resize 改为 `watchTheme()`——MutationObserver 盯 html/body 的 class/style/data-theme 属性、matchMedia 变化监听、8 秒低频兜底、`document.hidden` 时跳过（`getComputedStyle` 会强制样式重算）；`pagehide` 里 `teardown()` 统一清定时器/观察器
- `plugin-main.js`：`plan({desired})` 复用期望集合（原来先数一遍再让 plan 数一遍，200 条 1.48→0.75ms）；`rawKey/rawValue` 缓存 loadSyncedData 的解析结果；映射表按 host.tasks 清死 id（**原来只增不减，localStorage 无限增长**）；`selfDeleted` 登记自己删的任务，TASK_DELETE 钩子不再连锁触发重建；removeIds 去重；`stopAll` 放缓存
- `reminder-tasks.js`：`plan` 支持 `desired` 入参、`groups`/`wanted` 改无原型对象（防 `__proto__` 事件 id 串原型链）、备注只 parseMark 一次
- **修掉的实体 bug**：①编辑期间该条被同步删除 → 保存静默丢弃用户输入（现按新建落库，不复用旧 id）②点击已删除条目进入编辑态却改不动（`openSheet` 里 ev 为空时 id 归 null）③宿主回传对象而非 JSON 字符串时被当成空数据（`parseStored`）④`2026-04-31` 这类溢出日期 ⑤styles.css 两处 `transition: all` 收敛
- 验证：`npm test` 6 组全绿；另用 git worktree 拉 HEAD 旧代码做同条件对比（对比脚本已删）；jsdom 200 条切换筛选 44.9→39.9ms（其余为 jsdom 的 innerHTML 解析开销，真实浏览器占比更低）
